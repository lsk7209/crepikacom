티스토리 블로그 SEO 기초 세팅 팁: 개설 후 바로 해야 할 7가지

티스토리 블로그를 새로 개설했거나 SEO가 미흡한 분을 위한 기초 설정 가이드. 스킨 선택, 사이트맵 제출, 메타 설정 등 개설 직후 바로 해야 할 7가지 필수 작업입니다. 실전에서 즉시 쓸 수 있는 구체적인 팁들입니다.

핵심 개요

티스토리는 네이버 블로그보다 구글 SEO에 유리하고, 다양한 스킨과 플러그인으로 커스터마이징이 가능한 플랫폼입니다. 하지만 기본 설정 그대로 사용하면 SEO 효과가 제한적입니다. 개설 직후 7가지를 설정하면 검색 노출 기반을 제대로 다질 수 있습니다. 이 글에서 소개하는 방법들은 실제 운영 경험을 바탕으로 엄선한 실전 전략입니다. 실제 운영 현장에서 검증된 접근법으로, 지금 당장 적용할 수 있는 내용을 중심으로 구성했습니다. 이론보다 실전에 집중해, 읽고 나서 바로 실행할 수 있도록 정리했습니다. 반복 실험과 데이터 분석을 통해 효과가 입증된 방법만을 담았습니다. 실전에 바로 쓸 수 있는 글자수 세기과 해시태그 믹서을 활용하면 이 가이드의 내용을 더욱 빠르게 적용할 수 있습니다.

세팅 1~3: 스킨, 기본 정보, 사이트맵

세팅 1 빠른 스킨 선택: 반응형이고 로딩이 빠른 스킨을 선택하세요. 무거운 광고나 위젯이 많은 스킨은 페이지 속도를 낮춥니다. 구글 PageSpeed Insights에서 사이트 속도를 체크하고 80점 이상이 되는 스킨을 선택하는 것이 좋습니다. 세팅 2 블로그 기본 정보 완성: 관리자 → 블로그 → 기본 정보에서 블로그명, 설명, 키워드를 입력하세요. 블로그명은 메인 키워드를 포함하는 것이 좋고, 설명은 블로그의 주제와 독자가 얻을 가치를 명확히 써주세요. 세팅 3 구글 서치콘솔 사이트맵 제출: 티스토리는 /sitemap.xml이 자동으로 생성됩니다. 구글 서치콘솔에 sitemap.xml을 제출하면 구글이 빠르게 색인합니다. 네이버 서치어드바이저에도 같은 방법으로 제출하세요.

세팅 4~5: 카테고리와 메타 설정

세팅 4 카테고리 구조 최적화: 카테고리는 토픽 클러스터 전략을 반영해 설정하세요. 상위 카테고리(예: SEO 마케팅)와 하위 카테고리(예: 키워드 리서치, 링크 빌딩)로 구조화하면 내부 링크 구조가 자연스러워집니다. 카테고리 URL은 영문으로 설정하면 SEO에 유리합니다. 세팅 5 포스트 메타 설정 확인: 티스토리의 글쓰기 화면 하단에 "발행 설정"에서 썸네일, 요약, 태그를 설정할 수 있습니다. 요약(설명)은 메타 디스크립션 역할을 합니다. 크레피카 글자수/바이트 도구로 설명이 160자(한국어) 이내인지 확인하면서 작성하세요.

세팅 6~7: 구글 애널리틱스와 플러그인

세팅 6 구글 애널리틱스 연동: 티스토리 관리자 → 플러그인 → 구글 애널리틱스 플러그인을 설치하거나 HTML 직접 삽입 방식으로 GA4 코드를 head에 넣으세요. 트래픽 소스와 인기 포스트를 파악하면 콘텐츠 전략을 데이터 기반으로 개선할 수 있습니다. 세팅 7 필수 플러그인만 설치: 티스토리는 플러그인이 많을수록 로딩이 느려집니다. 꼭 필요한 것만 설치하세요. 추천: 반응형 이미지, 코드 신택스 하이라이터(기술 블로그의 경우), 공유 버튼. 불필요한 SNS 공유 버튼이나 방문자 통계 위젯은 속도를 낮추므로 제거하세요. 이미지는 크레피카 WebP 변환 도구로 최적화해서 올리면 로딩 속도를 크게 개선할 수 있습니다.

티스토리 vs 네이버 블로그: 무엇을 선택해야 하나

구글 트래픽이 목표라면: 티스토리가 훨씬 유리합니다. 구글은 네이버 블로그를 외부 블로그로 분류해 순위를 낮게 주는 경향이 있습니다. 티스토리는 독립 도메인 설정이 가능하고 HTML 수정이 자유로워 구글 SEO에 훨씬 유리합니다. 네이버 트래픽이 목표라면: 네이버 블로그가 유리합니다. 네이버 VIEW 알고리즘은 네이버 플랫폼 내 블로그를 우선 노출합니다. 두 가지를 모두 원한다면: 메인 콘텐츠는 티스토리에서 구글 SEO로 운영하고, 네이버 블로그는 요약본이나 일상 콘텐츠로 운영하는 투 채널 전략도 효과적입니다.

마무리

티스토리 SEO는 개설 초기 세팅이 90%를 결정합니다. 빠른 스킨, 사이트맵 제출, GA4 연동, 메타 설명 최적화 4가지만 제대로 해도 구글 검색 유입이 눈에 띄게 달라집니다. 꾸준한 실행이 결국 눈에 띄는 성과로 이어집니다. 오늘 배운 내용을 하나씩 적용해나가면 의미 있는 변화가 시작됩니다.

자주 묻는 질문

티스토리 독립 도메인 설정은 어렵나요?

도메인 구매(연 1~2만원)와 티스토리 관리자 → 개인 도메인 설정에서 CNAME 레코드를 추가하면 됩니다. 가비아, 카페24, Namecheap 등 도메인 업체에서 구매한 후 DNS 설정에서 tistory.com으로 CNAME을 연결하면 됩니다. 설정 후 반영까지 최대 24시간이 걸립니다.

티스토리 글은 구글 색인이 얼마나 빠른가요?

서치콘솔에 사이트맵을 제출하고 색인 요청을 하면 보통 1~3일 내로 구글이 색인합니다. 도메인을 처음 등록하거나 새 블로그라면 2~4주가 걸릴 수 있습니다. 꾸준히 포스팅하면 구글 봇의 방문 주기가 짧아져 색인 속도가 빨라집니다.

티스토리 카카오 로그인 의무화 후 노출이 줄었나요?

2023년 카카오 통합 이후 일부 블로거들이 노출 감소를 경험했습니다. 이는 플랫폼 변경에 따른 색인 재정리 과정으로 보이며, 콘텐츠 품질을 유지하면 점차 회복됩니다. 구글 SEO 기반의 트래픽은 플랫폼 정책 변경의 영향을 덜 받습니다.

티스토리 애드센스 승인은 어렵나요?

티스토리는 독립 도메인을 사용하면 애드센스 신청이 가능합니다. 승인 기준은 포스트 수(최소 10~20개), 콘텐츠 품질(복사 없이 직접 작성), 개인정보처리방침 페이지 존재입니다. 네이버 블로그는 애드센스 승인이 불가능하므로 수익화가 목표라면 티스토리가 유리합니다.

티스토리 포스트 URL(퍼머링크)은 어떻게 설정해야 하나요?

관리자 → 블로그 → 꾸미기 → 경로 설정에서 포스트 URL 형식을 설정할 수 있습니다. SEO에는 "숫자 + 제목 슬러그" 형식보다 "글 번호"만 있는 기본 형식이 더 짧고 관리하기 쉽습니다. 한국어 제목을 슬러그로 사용하면 URL 인코딩 문제가 생길 수 있으므로 영문 슬러그를 사용하거나 기본 숫자 URL을 유지하세요.

사이트 검토 정보

크레피카는 크리에이터와 마케터를 위한 무료 유틸리티 사이트입니다. 실무 도구, 편집 가이드, 문의 정보, 개인정보처리방침, 이용약관, RSS, robots.txt, ads.txt, 사이트맵을 제공해 사용자와 검색엔진이 자바스크립트 렌더링에만 의존하지 않고 사이트 구조를 이해할 수 있게 합니다.

광고는 Google AdSense 자동 광고로 노출될 수 있습니다. 이 정적 크롤러 페이지에는 수동 광고 슬롯을 삽입하지 않으며, 광고는 도구 결과나 편집 추천 내용에 영향을 주지 않습니다.
