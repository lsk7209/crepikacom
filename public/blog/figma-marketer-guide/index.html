Overview

Figma는 더 이상 디자이너만의 전유물이 아닙니다. 마케터, 콘텐츠 크리에이터, 스타트업 대표까지 모두가 Figma로 직접 비주얼을 제작하는 시대입니다. 처음 열면 복잡해 보이지만, 마케팅에 필요한 기능의 20%만 익혀도 업무 효율이 2배 이상 올라갑니다. 이 가이드는 디자인 배경 없이 Figma를 처음 여는 마케터를 위해 준비했습니다. 이 글에서 소개하는 전략과 팁들은 실제 운영 경험을 바탕으로 엄선했습니다. 단계별로 적용하면 가시적인 변화를 확인할 수 있습니다. 이 글에서 소개하는 방법들은 실제 운영 경험을 바탕으로 엄선한 실전 전략입니다. 실전에 바로 쓸 수 있는 글자수 세기과 WebP 변환기을 활용하면 이 가이드의 내용을 더욱 빠르게 적용할 수 있습니다.

Figma 무료 계정으로 시작하기

Figma는 무료 플랜으로 대부분의 마케팅 작업을 소화할 수 있습니다. 무료 플랜에서 가능한 것들: 프로젝트 3개, 파일 당 3명 공동 작업, 기본 컴포넌트, 커뮤니티 리소스 다운로드. 첫 설정 순서: 1. figma.com 가입 후 웹 버전 또는 데스크톱 앱 설치 2. New Design File 클릭 3. 프레임(F 단축키) 생성 — 소셜미디어 프리셋 선택 (Instagram Post, Twitter Post 등) 4. 작업 시작 처음에는 커뮤니티 템플릿을 활용하는 것이 가장 빠릅니다. Figma Community에서 "Instagram post", "YouTube thumbnail" 등을 검색하면 무료 템플릿이 수백 개 있습니다. 이미 만들어진 구조에 텍스트와 색상만 바꾸면 그것이 내 디자인이 됩니다.

마케터가 꼭 알아야 할 핵심 기능 5가지

복잡한 기능 다 몰라도 됩니다. 이 5가지만 익히면 소셜 카드, 배너, 썸네일을 자유롭게 만들 수 있습니다. 1. 프레임(Frame): 캔버스 역할. F를 누르고 드래그하거나 오른쪽 사이드바에서 프리셋 선택. Instagram 1080x1080, YouTube 1280x720 등 주요 사이즈가 기본 제공됩니다. 2. 텍스트(T): T 키 입력 후 클릭. 폰트, 크기, 줄 간격, 자간 등 세부 조정은 오른쪽 패널에서. 한글 폰트는 Google Fonts에서 Noto Sans KR, Nanum Gothic 등을 추가할 수 있습니다. 3. 오토 레이아웃: 여러 요소를 묶어 간격을 자동으로 맞춰주는 기능. Shift+A로 적용. 반응형 디자인의 핵심이며, 텍스트가 늘어나도 레이아웃이 자동으로 조정됩니다. 4. 컴포넌트: 반복 사용하는 요소(버튼, 헤더 등)를 마스터로 만들어두면 수정 시 모든 인스턴스가 동시에 바뀝니다. 시리즈 콘텐츠 제작에 필수. 5. Export: 완성된 프레임을 PNG, JPG, SVG, PDF로 내보냅니다. 오른쪽 패널 하단에서 배율(1x, 2x)과 형식 선택. 소셜미디어용은 PNG 2x 권장.

소셜 카드 제작 실전 워크플로우

인스타그램 카드형 콘텐츠를 처음부터 만드는 과정을 단계별로 설명합니다. 1단계: 프레임 생성 F 키 → 오른쪽 패널 상단 Instagram Post 선택 → 1080x1080 프레임 생성 2단계: 배경 설정 프레임 선택 후 오른쪽 Fill에서 색상 선택 또는 그라디언트 적용. 그라디언트는 Fill 옆 아이콘 클릭 → Linear 선택. 3단계: 텍스트 배치 T 키 → 헤드라인 입력. 중요 키워드는 Bold, 크기 4864px. 서브 텍스트는 Regular, 2432px. 텍스트 색상은 배경과 명도 차이가 충분한지 확인. 4단계: 브랜드 로고/아이콘 삽입 Ctrl+Shift+K 또는 상단 메뉴 Place Image로 이미지 삽입. 크레피카의 QR 생성 도구나 글자수 카운터 화면을 스크린샷해서 활용하면 실제 제품 화면이 들어간 마케팅 소재가 됩니다. 5단계: Export 프레임 우클릭 → Copy/Paste as → Copy as PNG. 또는 오른쪽 패널 하단 Export → + 버튼 → PNG 2x → Export 버튼. 여기서 글자수 확인이 중요합니다. 인스타 카드의 경우 헤드라인 25자 이내, 서브텍스트 50자 이내가 가독성에 최적입니다. 크레피카의 글자수 카운터로 미리 체크하면 디자인 중간에 텍스트를 수정하는 번거로움이 없어집니다.

Figma 협업 기능으로 팀 효율 높이기

Figma의 진짜 강점은 실시간 협업입니다. 마케팅 팀이 Figma를 제대로 활용하면 피드백 사이클이 극적으로 단축됩니다. 공유 링크: 상단 Share 버튼 → Can view 권한으로 링크 생성. 외부 에이전시나 클라이언트에게 편집 없이 검토만 가능한 링크 제공. 코멘트: C 키 눌러 코멘트 모드 진입 → 원하는 위치에 클릭하면 코멘트 추가. 디자이너와 마케터가 같은 화면에서 피드백 주고받기 가능. 이메일 알림 자동 발송. 버전 관리: File → Save to Version History로 스냅샷 저장. 수정 전 버전으로 언제든 롤백 가능. 팀 라이브러리: 자주 쓰는 컴포넌트(버튼, 색상, 폰트 스타일)를 팀 라이브러리에 올려두면 모든 팀원이 일관된 디자인 시스템 사용 가능. 마케팅 팀에서 Figma를 도입할 때 가장 흔한 실수는 모든 기능을 처음부터 익히려는 것입니다. 먼저 소셜 카드 1개를 끝까지 만들어보는 것이 가장 빠른 시작법입니다.

Conclusion

Figma는 처음엔 낯설지만, 1~2시간만 투자하면 기본 소셜 카드를 혼자 만들 수 있습니다. 디자이너에게 매번 요청하는 대신 직접 시안을 만들어 빠른 피드백을 받으면 캠페인 속도가 달라집니다. 커뮤니티 템플릿 → 텍스트/색상 교체 → Export 이 흐름부터 익히고, 크레피카의 글자수 카운터로 텍스트 분량을 최적화하세요. 처음에는 작게 시작해도 괜찮습니다. 실제로 적용하고 결과를 측정하는 과정에서 더 빠른 성장이 일어납니다.

FAQ

Figma 무료 플랜으로 마케팅 작업이 충분한가요?

대부분의 경우 충분합니다. 무료 플랜에서 프로젝트 3개, 기본 공동 작업, 커뮤니티 템플릿 사용이 모두 가능합니다. 팀원이 3명 이상이거나 고급 컴포넌트 기능이 필요하면 Pro 플랜($12/월)을 고려하세요.

Canva와 Figma 중 마케터에게 어느 것이 더 좋나요?

Canva는 더 쉽고 템플릿이 풍부해 빠른 제작에 유리합니다. Figma는 협업, 컴포넌트 관리, 브랜드 시스템 구축에 강합니다. 팀과 협업하거나 일관된 브랜드 디자인이 필요하다면 Figma, 혼자 빠르게 만든다면 Canva가 더 편리합니다.

Figma에서 한글 폰트를 쓰려면 어떻게 하나요?

Google Fonts에서 Noto Sans KR, Nanum Gothic, Pretendard 등을 검색해 텍스트 패널에서 직접 적용할 수 있습니다. 데스크톱 앱을 사용하면 컴퓨터에 설치된 폰트도 사용 가능합니다.

Figma에서 만든 디자인을 PPT로 내보낼 수 있나요?

Figma는 PDF로 내보내는 기능이 있고, 이를 PowerPoint에서 열 수 있습니다. 하지만 편집 가능한 PPT 형식으로 직접 내보내는 기능은 없습니다. "Figma to PowerPoint" 플러그인을 활용하면 근사치의 변환이 가능합니다.

모바일에서 Figma를 쓸 수 있나요?

Figma Mobile 앱(iOS/Android)에서 디자인을 확인하고 코멘트를 달 수 있습니다. 하지만 실질적인 편집 작업은 데스크톱에서 하는 것이 효율적입니다.
