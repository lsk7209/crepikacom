핵심 개요

티스토리는 네이버 블로그와 달리 구글 검색 결과에 직접 노출되는 구조로, SEO를 제대로 적용하면 구글 오가닉 트래픽을 대량으로 확보할 수 있습니다. 그러나 많은 티스토리 블로거가 SEO 최적화를 기초 단계(글 제목에 키워드 포함, 메타 설명 작성)에서 멈추고, 심화 최적화로 나아가지 못합니다. 이 케이스의 주인공인 직장인 재테크 블로그 '월급쟁이 투자노트'를 운영하는 조현민 씨는 창업 1년 후 유기 트래픽이 월 5000명 수준에서 정체됐습니다. 구글 Search Console에서 확인하니 상위 노출(클릭 유발 가능한 상위 10위 이내) 키워드가 7개에 불과했습니다. SEO 심화 최적화 과정을 6개월간 단계적으로 실행한 결과, 상위 노출 키워드가 52개로 증가하고 월 유기 트래픽이 2만 8000명으로 성장했습니다.

티스토리 SEO의 기술적 기반 점검

SEO 최적화를 시작하기 전에 기술적 기반을 점검했습니다. 구글 Search Console에서 '커버리지' 탭을 확인하니 조현민 씨 블로그의 포스팅 중 18%가 '크롤링됐지만 색인 안됨' 상태였습니다. 색인이 되지 않으면 구글에 노출이 불가능합니다. 색인 안됨의 주요 원인은 두 가지였습니다. 첫째, 중복 콘텐츠 문제. 티스토리는 동일한 포스팅이 카테고리 URL과 태그 URL로 중복 접근 가능한 구조입니다. 구글이 이를 중복으로 인식해 일부 URL의 색인을 제외했습니다. 이 문제는 Canonical 태그를 본문 URL로 지정해 해결했습니다. 둘째, 너무 짧은 콘텐츠. 500자 이하의 짧은 포스팅은 구글이 '가치 없는 콘텐츠'로 판단해 색인에서 제외하는 경향이 있습니다. 해당 포스팅들을 1500자 이상으로 업그레이드했습니다. 이 두 가지 기술적 수정 후 색인률이 82%에서 94%로 상승했습니다.

Core Web Vitals 개선으로 페이지 경험 점수 높이기

구글은 2021년부터 페이지 경험(Core Web Vitals)을 랭킹 요소로 공식 반영했습니다. 조 씨 블로그의 Core Web Vitals 점수를 Google PageSpeed Insights로 확인하니 모바일 기준 41점(100점 기준)으로 매우 낮았습니다. 주요 개선 항목은 세 가지였습니다. 첫째, 이미지 최적화. 포스팅에 삽입된 이미지들이 원본 크기(5MB~10MB)로 업로드되어 있었습니다. 모든 이미지를 WebP 포맷으로 변환하고 크기를 최대 800px로 제한했습니다. 이미지 용량이 평균 90% 감소했습니다. 둘째, JavaScript 지연 로딩. 티스토리 스킨에 포함된 불필요한 JavaScript를 제거하고, 나머지는 페이지 하단으로 이동해 콘텐츠 로딩 속도에 영향을 주지 않도록 했습니다. 셋째, Google Fonts를 로컬 폰트로 대체해 외부 폰트 로딩 시간을 없앴습니다. 이 개선 후 모바일 PageSpeed 점수가 41점에서 78점으로 상승했습니다.

콘텐츠 클러스터 구조로 주제 권위 강화

SEO 심화 전략 중 가장 강력한 것은 주제 클러스터(Topic Cluster) 구조입니다. 재테크 블로그라는 넓은 주제 안에서 '주식 투자', 'ETF', '연금 준비', '절세 전략', '부동산'이라는 5개 핵심 주제 클러스터를 정의했습니다. 각 클러스터에 대해 '기둥 페이지(Pillar Page)'와 여러 개의 '클러스터 페이지'를 체계적으로 구성했습니다. 기둥 페이지는 해당 주제의 포괄적인 완전 가이드(3000자 이상)이고, 클러스터 페이지는 세부 주제를 다루는 글(1500~2000자)로 모두 기둥 페이지와 내부 링크로 연결됩니다. 이 구조를 만들기 위해 기존 포스팅을 재분류하고, 부족한 클러스터 페이지를 새로 작성했습니다. 클러스터 구조 구축 후 각 기둥 페이지의 구글 순위가 평균 8단계 상승했습니다. 구글은 특정 주제에 여러 관련 글이 체계적으로 연결된 블로그를 해당 주제의 '권위 있는 소스'로 인식합니다.

검색 의도 매핑: 키워드에 맞는 콘텐츠 형식

동일한 키워드도 검색하는 사람의 의도에 따라 원하는 콘텐츠 형식이 다릅니다. 조 씨는 상위 노출을 원하는 키워드 20개의 검색 의도를 분석했습니다. 검색 의도는 크게 정보형(Howto, 개념 설명), 비교형(A vs B), 목록형(Best N, 추천), 가이드형(완전 가이드)으로 나뉩니다. 기존 포스팅과 검색 의도가 맞지 않는 경우를 발견했습니다. 예를 들어 'ETF 추천' 키워드로 작성한 글이 ETF 개념 설명 형식이었는데, 구글 상위 결과를 보니 모두 '목록형(Top 5 ETF)' 형식이었습니다. 검색 의도와 형식을 맞추도록 포스팅을 리라이팅했습니다. 검색 의도 매핑 후 수정한 포스팅 12개 중 9개가 2~4주 내에 이전 순위보다 평균 12단계 상승했습니다.

Featured Snippet 공략으로 0위 노출 확보

Google Featured Snippet은 검색 결과 1위 위에 박스 형태로 표시되는 '0위' 노출입니다. 검색 클릭률의 8~12%를 차지하는 귀중한 자리입니다. Featured Snippet은 '질문형' 검색어에서 주로 나타나며, 직접적으로 명확한 답변을 제공하는 콘텐츠가 선택됩니다. 조 씨는 Featured Snippet 최적화를 위해 다음 방법을 사용했습니다. 포스팅 내에 'Q: [질문]' → 'A: [100자 이내 직접 답변]' 구조를 추가했습니다. FAQ 섹션을 각 포스팅 하단에 추가하고, 자주 묻는 질문에 간결한 답변을 제공했습니다. 단계별 설명이 필요한 내용은 번호 매기기 목록으로 작성했습니다(구글이 단계 목록을 Featured Snippet으로 선택하는 비율이 높습니다). 이 최적화 후 6개월 안에 Featured Snippet 7개를 획득했고, 이 포스팅들의 클릭률이 평균 3.2배 상승했습니다.

6개월 성과 측정과 지속 가능한 SEO 루틴

6개월간 SEO 심화 최적화 작업 결과를 정리합니다. 구글 상위 10위 이내 키워드 수 7개 → 52개, 월 유기 트래픽 5000명 → 28,000명(5.6배), Featured Snippet 획득 수 0개 → 7개, 평균 페이지 이탈율 78% → 62%, 평균 세션 지속 시간 1분 42초 → 3분 18초. 이 성과를 유지하기 위한 월간 SEO 루틴은 다음과 같습니다. 매주: 구글 Search Console에서 'CTR이 낮은 상위 노출 키워드' 확인 후 해당 포스팅 제목·메타 설명 A/B 테스트. 매월: 신규 키워드 갭 분석으로 포스팅 아이디어 10개 발굴. 분기: Core Web Vitals 점수 재확인 및 저하된 페이지 개선. 반기: 클러스터 구조 검토 및 내부 링크 강화. 이 루틴을 유지하면 SEO 성과가 시간이 지날수록 누적 복리 효과를 냅니다. 지속적인 모니터링과 개선을 통해 더 좋은 결과를 만들어갈 수 있습니다.

마무리

티스토리 SEO는 기술적 기반, 페이지 속도, 콘텐츠 구조, 검색 의도, Featured Snippet이라는 다섯 가지 차원을 동시에 최적화할 때 극적인 성과가 납니다. 조 씨의 케이스는 이 다섯 가지를 체계적으로 실행하면 6개월이라는 단기간에도 트래픽 5배 이상 성장이 가능하다는 것을 보여줍니다. 지금 여러분의 블로그 Search Console에서 색인률과 상위 노출 키워드 수부터 확인해보십시오.

자주 묻는 질문

티스토리 블로그에서 Canonical 태그를 어떻게 설정하나요?

티스토리 관리자 화면의 '꾸미기 스킨 편집 HTML 편집'에서 헤드 태그 내에 Canonical 태그를 추가할 수 있습니다. 또는 SEO 플러그인이나 스킨에 따라 설정 메뉴에서 자동 Canonical 설정이 가능합니다. 가장 간단한 방법은 각 포스팅의 '발행 설정'에서 Canonical URL을 직접 지정하는 것입니다.

구글 Search Console의 'CTR이 낮은 상위 노출 키워드'를 어떻게 찾나요?

Search Console의 '검색 결과' 탭에서 필터를 '위치 = 10 이하'(상위 10위)로 설정하고, CTR 열을 기준으로 오름차순 정렬합니다. 노출 수는 많지만 CTR이 낮은 키워드는 제목이나 메타 설명이 매력적이지 않다는 신호입니다. 이 키워드들의 제목과 메타 설명을 개선하면 광고 없이 클릭 수를 높일 수 있습니다.

티스토리에서 WebP 이미지를 사용하는 방법이 있나요?

티스토리는 이미지를 직접 WebP로 변환해 업로드하는 방법이 가장 간단합니다. 무료 이미지 변환 도구(Squoosh, CloudConvert 등)로 JPG/PNG를 WebP로 변환한 뒤 업로드하면 됩니다. 일부 스킨에서는 자동 WebP 변환을 지원하기도 합니다. 이미지 업로드 전 크기를 최대 800~1200px로 리사이즈하는 것도 잊지 마세요.

Google Featured Snippet을 얻으려면 포스팅이 상위 몇 위에 있어야 하나요?

Featured Snippet은 주로 상위 1~5위 포스팅에서 선택되지만, 상위 10위 안에 있는 포스팅도 획득하는 경우가 있습니다. 가장 핵심은 순위보다 콘텐츠의 형식입니다. 질문에 직접적으로 명확하게 답하는 구조, 번호 목록이나 표 형식, 100자 이내의 직접 답변이 Featured Snippet에 선택될 가능성을 높입니다.

구글 SEO와 네이버 SEO를 동시에 최적화할 수 있나요?

일부 요소는 겹치지만(고품질 콘텐츠, 빠른 로딩 속도) 알고리즘 차이로 인해 충돌하는 부분도 있습니다. 네이버는 포스팅 빈도를 중요시하는 반면, 구글은 포스팅 품질과 깊이를 더 중시합니다. 두 플랫폼을 동시에 공략하려면 블로그의 주 수익 모델과 타겟 독자를 먼저 결정하고, 그에 맞는 플랫폼에 최적화를 집중하는 것이 현실적입니다.

사이트 검토 정보

크레피카는 크리에이터와 마케터를 위한 무료 유틸리티 사이트입니다. 실무 도구, 편집 가이드, 문의 정보, 개인정보처리방침, 이용약관, RSS, robots.txt, ads.txt, 사이트맵을 제공해 사용자와 검색엔진이 자바스크립트 렌더링에만 의존하지 않고 사이트 구조를 이해할 수 있게 합니다.

광고는 Google AdSense 자동 광고로 노출될 수 있습니다. 이 정적 크롤러 페이지에는 수동 광고 슬롯을 삽입하지 않으며, 광고는 도구 결과나 편집 추천 내용에 영향을 주지 않습니다.
